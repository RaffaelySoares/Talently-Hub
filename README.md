# 🌟 Talently Hub  
### Conectando talentos e guiando transições de carreira

O **Talently Hub** é uma plataforma criada para ajudar pessoas que desejam **migrar de carreira**.  
A landing page apresenta recursos essenciais como orientação profissional, cursos recomendados, vagas exclusivas e um roadmap personalizado para quem está iniciando uma nova jornada profissional.

Este repositório contém o código da **Landing Page Talently Hub**, desenvolvida com foco em:
- UX acessível  
- Estruturação clara  
- Animações suaves  
- Conteúdo informativo  
- Layout moderno e responsivo  

---

## 🚀 Funcionalidades

### ✔ Hero Interativo  
Apresenta o propósito da plataforma com visual profissional e chamada clara para ação.

### ✔ Formulário de Cadastro  
Campos acessíveis e com foco em coleta de informações essenciais para personalização.

### ✔ Benefícios  
Mostra as principais vantagens em utilizar a plataforma.

### ✔ Seção "Sobre"  
Explica de forma objetiva a missão e o funcionamento do Talently Hub.

### ✔ Roadmap em 3 Etapas  
Apresenta o processo de migração profissional oferecido ao usuário.

### ✔ **Cursos Reais Recomendados**  
Sugestões de cursos gratuitos e confiáveis (Coursera, FGV, Alison, Pensar Cursos, IFPA, etc.)  
para apoiar o início da nova carreira.

### ✔ Conexões Recentes  
Demonstrativo de networking e interação entre usuários.

### ✔ Vagas Exclusivas  
Exibição de vagas simuladas para áreas populares no mercado de tecnologia.

### ✔ FAQ  
Dúvidas frequentes com componente nativo acessível `<details>`.

### ✔ CTA Final  
Botão “Começar Agora” com destaque e acessibilidade.

### ✔ Newsletter  
Input para receber vagas semanalmente.

## ♿ Acessibilidade (A11y)

A landing page foi construída considerando as recomendações da **WCAG 2.1**, incluindo:

- Uso de roles semânticos (`header`, `nav`, `main`, `footer`, `section`)  
- Textos alternativos (`alt`) em todas as imagens  
- Labels associados aos inputs  
- Foco visível ao navegar via teclado  
- Elementos `<details>` e `<summary>` para FAQ  
- Aria-labels e aria-labelledby para leitura correta por leitores de tela  
- Cores com contraste adequado  
- Animações suaves e seguras (sem flashes)
